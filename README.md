# 图形学物理仿真 Project

## Introduction

In the project, we implement a simple fluid-structure interaction simulator.

## Project Structure

- `src/VCX/Scene`: The scene management module, which is responsible for loading and managing 3D models, textures, and other assets.
- `src/VCX/Simulation`: The fluid simulation module, which implements the fluid simulation algorithms and the main application logic.
- `src/VCX/Engine`: The graphics engine module, which provides rendering capabilities and other low-level functionalities.
- `src/VCX/Common`: The common utilities and helper functions used across the project.
- `src/VCX/Assets`: The assets used in the project, such as 3D models, textures, and shaders.
